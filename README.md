# Tactical DDD : Redonnons du sens au code par la pratique

## Speakers
* **Adriana Nava Aguilar** — Senior Software Engineer
* **Dorra Bartaguiz** — CTO

---

## Description
Domain-Driven Design (DDD) impressionne encore. Trop souvent perçu comme une théorie complexe réservée à une élite, c'est pourtant directement dans le code que le DDD prend tout son sens. 

Nous vous proposons un **atelier 100% pratique** pour lever les barrières du jargon. À travers un cas d’usage concret, nous découvrirons étape par étape comment structurer notre code — surtout à l’ère de l’IA — et comment faire émerger la logique métier.

### Au programme de cette session immersive :
* **La trinité tactique en action :** Implémentation pas-à-pas de *Value Objects*, *Entities* et *Aggregates* pour terrasser les modèles anémiques.
* **Du code, pas du fluff :** Alternance de phases de live-coding et de mises en perspective théoriques pour ancrer les concepts (*langage omniprésent*, *bounded contexts*).
* **Le DDD augmenté par l'IA :** Comment utiliser les LLM pour générer des composants conformes et détecter les violations de design sans saborder votre architecture.

---

> Que vous soyez novice ou en quête de validation, vous découvrirez des techniques concrètes pour exprimer toute la saveur de votre métier dans votre code. Étonnez-vous à pratiquer le DDD avec plaisir et simplicité !
